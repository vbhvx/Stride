# AI Governance, Grounding & Operating Boundaries

## 1. Operating Principles & Boundaries

In accordance with the NIST AI Risk Management Framework (Govern, Map, Measure, Manage):

1. **Advisory Assistance Only**: AI synthesizes records into drafts. It is never an automated judge of human careers.
2. **No Promotion Scores**: The system strictly forbids generating "promotion probabilities", "employee scores", or universal leaderboards.
3. **Mandatory Grounding**: Every material claim generated by the assistant must reference an authorized, underlying evidence ID or goal ID.
4. **Context & Uncertainty Representation**: Missing evidence is framed as an *evidence gap* or opportunity constraint, not as demonstrated inability.
5. **Prompt Injection Defense**: All user inputs (feedback text, goal descriptions, evidence records) are treated as untrusted and sanitized against prompt escape sequences and delimiter manipulation.
6. **Data Minimization**: Prompts only receive authorized records within the requester's permission scope. Restricted manager notes are never included in employee-requested runs.
7. **Human-in-the-Loop Oversight**: Every run is tagged with human review status:
   - `PENDING_REVIEW`
   - `ADOPTED_VERBATIM`
   - `EDITED_AND_ADOPTED`
   - `REJECTED`
8. **Graceful Fallback**: If an external provider is unreachable or disabled, standard platform reviews and manual development planning remain 100% operational.
